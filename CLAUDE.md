# CLAUDE.md

The full working rules for this repository are kept in a private companion repository, cloned next to this one at
`~/dgg-chat-private`. The line below loads them when that clone exists:

@~/dgg-chat-private/CLAUDE.md

If they did not load, clone `dgg-chat-private` before changing anything here. Public summary: predictions are committed
before the data they predict is read (`docs/*-predictions.md`); an existing prediction is never edited, only
followed by dated addenda; results, misses included, go in a separate `*-results.md` file. No personal names,
private machine details or internal notes go in this public repository.
